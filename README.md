# Hexagon Research

This repository contains research notebooks and analysis results across multiple domains including Constitution & Law, Culture, Religion & Literature, Economy, Technology, Education, Health, Geography, Tourism, and HalluVerse and Poly-FEVER datasets. Each research notebook explores specific topics using the Gemma 3.1B language model, generating comprehensive analysis and results stored in corresponding Excel files. The project systematically investigates various research areas through computational analysis and provides detailed summaries and QA outputs for each domain.
